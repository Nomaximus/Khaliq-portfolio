# Abdul Khaliq Portfolio

A static portfolio website for Abdul Khaliq, an Information System Management student.

## Open locally

Open `index.html` in a browser. No build tools or installation are required.

For the most reliable local preview, serve the folder with any simple static web server.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload all files and the `Img` folder from this directory.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Open the Pages URL shown by GitHub after deployment finishes.

## Project structure

- `index.html` - Homepage
- `about.html` - About page
- `skills.html` - Skills page
- `projects.html` - Projects page
- `experience.html` - Experience page
- `contact.html` - Contact page
- `style.css` - Shared custom styles
- `script.js` - Shared interactions
- `Img/` - Portfolio images

## External services

The site loads Google Fonts, Font Awesome, and Tailwind CSS from CDNs, so an internet connection is needed for the complete visual experience.
